사용 안내

처음 사용하는 순서
  1. 시청 화면에서 영상 추가를 눌러 주소나 파일을 넣습니다. 처음 넣은 영상이 큰 메인 화면이 돼요.
  2. 싱크 맞추기를 켜고 영상마다 같은 장면(예: 곡이 시작하는 순간)을 찾아 둡니다.
  3. 아래 재생 버튼을 누르면 모든 영상이 맞춘 위치 관계대로 함께 재생돼요.
  4. 자주 보는 조합은 세트 저장으로 남겨 두면 다음에 바로 불러올 수 있습니다.
  5. 맞춘 결과를 영상 하나로 남기고 싶으면 녹화에서 배치를 정하고 녹화하면 돼요.
치지직 다시보기 넣는 법
  1. 치지직은 외부 재생용 플레이어가 없어서 다시보기 페이지 주소(chzzk.naver.com/video/…)는 쓸 수 없어요.
  2. PC 크롬에서 다시보기 페이지를 열고 F12 → Network 탭을 연 뒤 F5로 새로고침합니다.
  3. 위쪽 종류 버튼에서 All을 누르고, 필터 칸에 playback을 입력합니다.
  4. 나온 줄을 더블클릭하면 새 탭에 글자가 가득한 화면(XML)이 열려요. 그 화면에서 Ctrl+A, Ctrl+C로 전부 복사합니다.
  5. 영상 추가 창에 그대로 붙여넣으면, 가장 좋은 화질의 주소를 알아서 골라 넣어 줘요.
  6. 생방송 다시보기 중에는 m3u8 주소로 재생되는 것도 있어요. 이때는 필터에 m3u8을 넣어 찾으면 됩니다.

스트림 주소는 시간이 지나면 만료될 수 있어요. 저장한 세트가 열리지 않으면 주소를 새로 복사해 넣으세요.

싱크 맞추는 법
  • 싱크 맞추기를 켜면 트랙마다 개별 슬라이더가 생겨요. 영상 하나씩 같은 장면으로 옮겨 두세요.
  • 미세 조정은 트랙의 ±0.1초, ±1초 버튼이나 숫자 칸으로 합니다. 값이 클수록 그 영상이 앞서 나가요.
  • 재생 중에 어긋남이 생기면 자동으로 다시 맞추고, 한 영상이 버퍼링하면 모두 잠깐 기다렸다 함께 재생합니다.
녹화해서 영상 하나로 저장하기
  1. 시청 화면 위쪽의 녹화를 누르면 녹화 화면 미리보기가 열려요.
  2. 화면 크기(가로·세로·정사각)와 배치를 고르고, 미리보기에서 영상을 끌어 위치와 크기를 원하는 대로 바꿉니다.
  3. 녹화 시작을 누르면 싱크가 맞은 상태로 재생되면서 녹화돼요. 일시정지하면 녹화도 멈추고, 버퍼링 구간은 녹화에서 빠집니다.
  4. 끝나면 미리 보고 다운로드합니다. 크롬·엣지 최신 버전은 mp4, 그 밖에는 webm 파일로 저장돼요.

녹화는 실제 재생 속도로 진행돼서 1시간 영상은 1시간이 걸려요. 녹화 중 다른 탭으로 옮기면 화면이 멈춘 채 녹화될 수 있어요.

단축키
  • Space 재생 / 일시정지
  • ← → 5초 이동
  • 1~9 해당 번호 영상을 메인 화면으로
  • S 싱크 맞추기 켜기 / 끄기

영상은 이 브라우저 안에서만 재생되며 어디에도 업로드되지 않습니다. 세트에는 주소와 싱크 값만 저장돼요.

치지직 다시보기 주소는 어떻게 넣나요?

다시보기 페이지에서 F12 → Network → All 선택 → 필터에 playback → F5. 나온 줄을 더블클릭해 열린 화면을 Ctrl+A, Ctrl+C로 복사해 위 칸에 붙여넣으면 가장 좋은 화질로 들어가요. 주소는 하루쯤 지나면 만료돼요.
